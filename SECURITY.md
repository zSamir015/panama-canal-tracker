# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting: go to the **Security** tab of this repository and
click **Report a vulnerability**. You will get a response as soon as possible.

## Supported versions

Only the latest release on `main` receives security fixes.

## Scope

This is a portfolio project. The live demo uses public AIS data only; no personal data other than
user account emails is stored.
